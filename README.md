# DBT SQL Practice

This repository contains my **SQL practice, commands, queries, and outputs** from **DBT (Database Technologies)** as part of the **CDAC PGCP-AC** course.

The purpose of this repository is to keep track of the SQL concepts I learn and practice throughout the DBT module.

The repository will gradually include practice related to:

- DML (Data Manipulation Language)

- TCL (Transaction Control Language)
- Creating and modifying databases
- Creating and modifying tables
- INSERT, UPDATE, and DELETE
- SELECT queries
- WHERE, ORDER BY, and GROUP BY
- Aggregate Functions
- Joins
- Subqueries
- Constraints
- Primary Keys and Foreign Keys
- Views
- Indexes
- Functions
- Stored Procedures
- Triggers
- Transactions
- Other Database Technologies concepts
